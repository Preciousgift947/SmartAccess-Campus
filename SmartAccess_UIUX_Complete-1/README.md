# SmartAccess Campus – UI/UX Direction

This is a front-end UI/UX prototype based on the SmartAccess Campus proposal.

## User flow

STUDENT:
Login → Dashboard/Home → Profile / Digital ID Card / Attendance / Academic Calendar / Notifications

SECURITY/STAFF:
Login → Staff Dashboard → QR Scanner → Student Verification → Attendance/Access result → Reports

## Included screens

- Login
- Student Dashboard/Home
- Student Profile
- Digital Access Card / QR
- Attendance
- Academic Calendar
- Notifications
- Staff Dashboard
- QR Scanner
- Student Verification
- Reports

The QR Scanner, Student Verification and Academic Calendar screens are included as part of the existing project flow so the frontend pages can use the same navigation/header/sidebar.

## How to run

1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Choose "Open with Live Server".

This prototype uses demo data and localStorage. It does not connect to Node.js/MySQL yet.
